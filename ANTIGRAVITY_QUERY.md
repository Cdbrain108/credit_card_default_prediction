## Acceptance criteria (what was requested — check EVERY item)

### A. Notebook — `Credit_Default_Classification_Pipeline.ipynb` (generated by `build_notebook.py`)
1. Steps **in order**: Data Inspection → Data Cleaning → EDA → Feature Engineering →
   Data Preprocessing → Modelling → Model Comparison, with a **markdown cell before
   every operation**, written in the simple style of my attached notebooks.
2. Modelling contains **every** technique:
   - plain **Logistic Regression** (base) with accuracy / confusion matrix /
     classification report / cross-validation / ROC-AUC
   - **regularization**: L1 (Lasso), L2 (Ridge), ElasticNet — sweeping `C`
     (= 1/alpha) and keeping the best, plus the L1 sparsity check (zeros count)
   - **KNN** (yes, KNN must be there) with elbow sweep of `k`
   - **Decision Tree with feature importance**, **Bagging**, **Random Forest**,
     **AdaBoost**, **Gradient Boosting**, **XGBoost**, **SVM** (linear + RBF),
     **Naive Bayes**
3. Hyperparameters are checked **one by one**, not just one big grid search:
   - **first pick the best `random_state`** (checked 0–4, best used everywhere)
   - Decision Tree exactly like this: **full-length tree first** (shows overfitting) →
     sweep `max_depth` with **train vs test** curves → `criterion` (gini/entropy/log_loss)
     → `min_samples_leaf` → **feature selection** from `feature_importances_`
     (top-5/10/15/…) → **final tree** trained and evaluated on the selected features
     (+ a `plot_tree` visualisation)
   - the same "check every hyperparameter, keep the best" approach for **each** other
     model (n_estimators, learning_rate, depth, C, gamma, k, weights, p,
     var_smoothing …), with small matplotlib train/test plots
   - **GridSearchCV** used where it makes sense (cross-validation, scoring = ROC-AUC)
4. The notebook **executes top-to-bottom with ZERO errors** and its **last cell saves**
   `models/notebook_results.json` (best values per model + selected features).
